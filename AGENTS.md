# Инструкция для ИИ-агентов: добавление уроков в school-trainer

Этот файл читают ИИ-агенты (Claude, Codex, Cursor и др.) перед работой с репозиторием.
Готовый промт для постановки задачи агенту лежит в [`docs/prompt-new-lessons.md`](docs/prompt-new-lessons.md).

## 1. Что это за проект

Статический тренажёр для подготовки к уроку 7 класса (без сборки, без фреймворков).
Один параграф учебника = один JSON-файл `data/<предмет>/p<N>.json`, тема регистрируется в `data/subjects.json`.
Движок (`app.js`, `tools.js`, `catalog.js`) при добавлении уроков **не трогаем**.

Запуск для проверки: `python -m http.server` из корня → `http://localhost:8000/trainer.html?s=<предмет>&p=<N>`.

## 2. Главные правила

1. **Только учебник.** Весь текст, факты, даты, цифры, формулы, примеры, определения берутся из PDF параграфа. Ничего не добавлять из своих знаний, даже если «очевидно». Нет в учебнике — нет в уроке.
2. **Рисунки из учебника обязательны.** Каждый рисунок, схема, таблица, диаграмма, портрет, карта параграфа вырезается и подключается в урок. Декоративные заставки глав/разделов и иконки на полях не нужны.
3. **Формулировки определений — как в учебнике** (выделенные жирным/цветом фразы переносить дословно). Остальное можно сокращать, но не искажать смысл.
4. **Не плодить длинные тире.** Тире «—» только там, где оно есть в учебнике (определения «X — это Y», диапазоны дат «1643—1715»).
5. **Не менять стиль соседних файлов**, движок и форматирование `subjects.json` (темы записаны в одну строку).
6. Перед сдачей — `node scripts/check-data.mjs` без ошибок и просмотр урока в браузере.

## 3. Источники

PDF лежат в репозитории [Maks-T/pdf-book-splitter](https://github.com/Maks-T/pdf-book-splitter), папка `output/<источник>/`.
Имя файла: `<порядковый>_(<страницы>)_§<N>_<Название>.pdf`. Номер параграфа берите из `§N` в имени, а **не** из порядкового номера файла.

| Предмет (`id`) | Источник в `output/` | `num` в реестре | Что во вкладке «хронограф» (`timeline`) |
|---|---|---|---|
| Физика (`physics`) | `physics_7` | `§ 17` | «🔬 Опыты и примеры»: `date` — опыт/формула/пример, `title` — что это, `text` — описание с номером рисунка |
| Химия (`chemistry`) | `chemistry_7` | `§ 10` | «🧪 Формулы и расчёты»: `date` — формула/вещество, `title` — вывод, `text` — расчёт. Для параграфов без расчётов переопределяйте `labels` в JSON параграфа (см. `p10.json`) |
| Всемирная история (`history`) | `world_history_7` | `§ 9` | «⏳ Хронограф» (по умолчанию): `date` — «1641 год», «XVIII век», «Конец XVIII века» |
| История Беларуси (`history_bel`) | `history_bel_7` | `§ 11` | «⏳ Хронология»: `date` — «1557 г.», «1530—1540-е гг.» |
| Биология (`biology`) | `biology_7` | `§ 14` | Обычно нет (вкладка скрывается, поле `timeline` не пишем) |
| Английский (`english`) | `english_7` | `Lesson 9` | «📘 Грамматика»: конструкция → примеры |

Предметы со `status: "planned"` (алгебра, геометрия, русский, литература) — заглушки. Чтобы запустить предмет: создать `data/<id>/`, добавить уроки, заполнить `sections` и поставить `"status": "ready"`.

## 4. Порядок работы над параграфом

### 4.1. Найти и разобрать PDF

PDF — **сканы без текстового слоя** (`pdftotext` вернёт пустоту). Поэтому:

```bash
python scripts/pdf_tools.py pages "<путь>.pdf" work/<предмет><N> --ocr
```

Получите `p-000.jpg …` (страницы) и `p-000.txt …` (черновой OCR). **OCR только черновик**: индексы, формулы, дроби, римские цифры, даты и числа обязательно сверяйте, глядя на картинку страницы. Прочитайте **каждую** страницу глазами.

В PDF часто есть хвост предыдущего параграфа в начале и начало следующего в конце — их не берём.

### 4.2. Вырезать рисунки

1. По картинкам страниц определите прямоугольники рисунков в пикселях **исходной** страницы (размер печатает команда `pages`).
2. Опишите их в `spec.json` и вырежьте:
   ```bash
   python scripts/pdf_tools.py crop work/spec.json
   python scripts/pdf_tools.py sheet work/sheet.jpg data/<предмет>/img/p<N>_*.jpg
   ```
3. **Откройте контактный лист и проверьте**: рисунок целиком, без обрезанных краёв, без подписи «Рис. N…» внизу, без кусков соседнего текста и иконок на полях. Если не так — поправьте координаты и повторите.

Имена файлов: `data/<предмет>/img/p<N>_<что>.jpg`
- рисунок с номером: `p17_fig96.jpg`;
- таблица: `p17_table1.jpg`;
- без номера — короткое латинское имя по смыслу: `p11_bona.jpg`, `p10_london.jpg`, `p11_categories.jpg`.

### 4.3. Написать `data/<предмет>/p<N>.json`

```jsonc
{
  "id": "17",                                   // строка = N
  "title": "§ 17. Полное название как в учебнике",
  "subtitle": "Ключевые темы через запятую",
  "labels": { ... },                            // необязательно: свои названия вкладок (см. README)
  "toolContext": { ... },                       // необязательно: контекст для помощников (раздел 6)
  "sections": [
    {
      "title": "1. Название пункта",
      "text": "Текст с {ключевыми словами} в фигурных скобках.",
      "chain": ["Опорный пункт 1", "Опорный пункт 2", "Опорный пункт 3"],
      "images": [{ "src": "img/p17_fig96.jpg", "caption": "Рис. 96. Подпись из учебника" }]
    }
  ],
  "flashcards": [
    { "cat": "Определение", "q": "Вопрос?", "a": "Ответ.", "image": { "src": "img/p17_fig97.jpg", "caption": "Рис. 97", "side": "a" } }
  ],
  "timeline": [{ "date": "…", "title": "…", "text": "…" }],
  "quiz": [{ "q": "Вопрос?", "opts": ["А", "Б", "В", "Г"], "correct": 1 }]
}
```

**sections (суфлёр)** — 6–12 разделов, идут по порядку пунктов учебника. Последний раздел — «Главные выводы»/«Итоги», если в учебнике есть такой блок. Отдельными разделами — «Для любознательных», «Примеры решения задач», лабораторные опыты.
- `text` — связный пересказ пункта; в `{}` — то, что ученик должен назвать сам: термины, даты, имена, числа, формулы. Обычно 8–20 ключей на раздел, одна пара скобок без вложенности.
- `chain` — 3–6 коротких опорных пунктов (план ответа у доски).
- `images` — рисунки этого пункта, `caption` — подпись из учебника (номер рисунка, автор и год для картин). Необязательное поле `width` (px).

**flashcards** — 18–24 карточки: определения, формулы, даты, личности, причины/итоги, вопросы «Проверь себя» из учебника с ответами по тексту. `cat` — короткая категория («Определение», «Формула», «Личность», «Дата», «Причина», «Опыт»…). К карточкам по рисункам добавляйте `image`; `side: "q"` — если картинка нужна, чтобы ответить (например «какое движение на рис. 100 быстрее?»).

**timeline** — 8–14 записей, по смыслу предмета (таблица в разделе 3). У истории — в хронологическом порядке.

**quiz** — 12–14 вопросов, ровно 4 варианта, `correct` — индекс с нуля. Правильный ответ ставить на **разные** позиции. Неверные варианты правдоподобны, но однозначно неверны по учебнику. Помните: неверные варианты не попадают в контекст помощников, а вопрос и правильный ответ попадают.

### 4.4. Зарегистрировать тему в `data/subjects.json`

Добавьте строку в `topics` нужного раздела (одной строкой, как соседние):

```json
{ "p": 17, "num": "§ 17", "title": "Название параграфа", "desc": "Короткое описание: 5–10 ключевых понятий." },
```

Если параграф открывает новую главу/раздел учебника — добавьте новый объект в `sections` предмета с `title` по учебнику (например `"Глава 4. Общая характеристика растений"`).
Правьте файл точечно, не переформатируя его целиком.

### 4.5. Проверить

```bash
node scripts/check-data.mjs          # структура, картинки, тест, реестр — должно быть «✅ Ошибок нет»
python -m http.server 8000           # открыть урок и пройтись по всем вкладкам
```

В браузере проверьте: все картинки загружаются, нет ошибок в консоли, переключатель «⬅ / ➡» ведёт на соседние параграфы, помощники открываются.

### 4.6. Сдать результат

Список изменённых и новых файлов (`git status`) и, если просили, zip с этими файлами с сохранением путей от корня репозитория. В отчёте коротко: какие параграфы добавлены, что сделано иначе, чем просили, и почему.

## 5. Частые ошибки

- Номер параграфа взят из порядкового номера файла PDF, а не из `§N`.
- Параграф уже есть в `data/<предмет>/` — проверьте до начала работы; не перезаписывайте без явной просьбы.
- Факты «из головы» (годы жизни, второй пример, «интересный факт») — запрещено.
- Подписи «Рис. N» вырезаны вместе с рисунком, края обрезаны, захвачены иконки полей («книжка» с номерами страниц, «?»).
- Все `correct` равны 1.
- Фигурные скобки внутри формул или вложенные `{…{…}…}`.
- Индексы формул в тексте — используйте подстрочные символы: `H₂O`, `Al₂(SO₄)₃`, `t₀`, `v₁`.

## 6. Помощники (`tools`) и контекст параграфа

Кнопки «🧰 Помощники» задаются в `subjects.json → subject.tools` (типы — в README). Помощник получает **контекст открытого параграфа**:

- **Автоматически** — `tools.js` находит химические формулы во всех текстах параграфа (суфлёр, карточки, хронограф, вопрос и правильный ответ теста) и показывает их отдельным блоком «📖 Из § N». Калькулятор Mr показывает все формулы, калькулятор валентности — бинарные, у которых валентность определяется и совпадает с учебником, и пары элементов для составления формул.
- **Вручную** — поле `toolContext` в JSON параграфа. Ключ — `id` или `type` инструмента:

```jsonc
"toolContext": {
  "valence": {
    "formulas": ["HCl", "CH4", "CaCl2"],          // добавятся первыми (например, из «Вопросов и заданий»)
    "pairs": [["Fe", 3, "O", 2], ["C", 4, "Cl", 1]], // пары для режима «Формула по валентности»
    "auto": true                                   // false — не искать формулы в тексте
  },
  "mrcalc": { "formulas": ["Al2(SO4)3"] }
}
```

Пишите формулы так, как они в учебнике; в `toolContext` можно обычными цифрами. Записи валентности вида `Fe(III)`, `P(V)O(II)` автоматически не считаются формулами.

Таблица Менделеева использует контекст так: кнопка «📖 Элементы § N» подсвечивает элементы из формул и отдельно стоящих символов параграфа, а в сведениях об элементе показаны формулы со всех параграфов предмета, где валентность элемента определяется (`ptBuildValenceIndex()`). Значит, новые формулы в уроках химии сразу появляются в таблице.

Новый тип помощника: функция `render<Тип>(body, elements, ctx)` в `tools.js` + ветка в `openTool()`; `ctx` берите из `getToolContext()`. Помощник должен работать в любом режиме окна (по центру, справа, снизу, плавающее): вёрстка резиновая, при изменении размера приходит событие `tooldock` на `document`. Опишите тип в README.
