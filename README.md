# 🏫 school-trainer — единая платформа тренажёров 7 класса

Интерактивная платформа для подготовки к уроку и ответу у доски: **суфлёр, флеш-карточки, хронограф и экспресс-тест** по каждому параграфу. Объединяет все предметы 7 класса в одном репозитории.

Создано слиянием проектов `physics-trainer` и `history-trainer` (движок был идентичным, данные разделены по предметам).

> 🤖 **ИИ-агентам:** инструкция по добавлению уроков — [`AGENTS.md`](AGENTS.md), готовый промт для постановки задачи — [`docs/prompt-new-lessons.md`](docs/prompt-new-lessons.md).

## Запуск

Проект статический, но **требует локального сервера** (fetch JSON не работает по `file://`):

- VS Code: расширение **Live Server** → «Go Live», либо
- `npx serve .` / `python -m http.server`

## Навигация

```
index.html
  └─ subject.html?s=physics            (предмет)
       └─ trainer.html?s=physics&p=8   (параграф)
            🗣️ Суфлёр | 🃏 Карточки | ⏳ Хронограф | 🎯 Экспресс-тест
```

В тренажёре есть хлебные крошки, переключатель предмета в шапке и листание параграфов «⬅ / ➡» внизу. Вкладки, для которых нет данных (например, хронограф в физике), автоматически скрываются.

## Реестр предметов: `data/subjects.json`

```jsonc
{
  "grade": 7,
  "subjects": [
    {
      "id": "physics",            // используется в URL и в пути к данным
      "title": "Физика",
      "icon": "🔬",               // эмодзи-картинка предмета
      "color": "#059669",         // акцентный цвет темы (hex)
      "colorSoft": "#dcfce7",     // мягкий фон (hex)
      "description": "Краткое описание для карточки",
      "status": "ready",          // "ready" | "planned"
      "sources": ["physics_7"],   // папки-источники в pdf-book-splitter/output
      "sections": [               // группы тем (заголовки разделов учебника)
        {
          "title": "Раздел II. Строение вещества",
          "topics": [
            { "p": 8, "num": "§ 8", "title": "Дискретное строение вещества",
              "desc": "Молекулы, атомы, гипотеза Демокрита…" }
          ]
        }
      ]
    }
  ]
}
```

- `status: "ready"` — предмет с готовыми тренажёрами, `sections.topics` ведут на `trainer.html`.
- `status: "planned"` — карточка-заглушка «контент готовится», `sections` пустой.

## Формат данных параграфа: `data/<id>/p<number>.json`

```jsonc
{
  "id": "8",
  "title": "§ 8. Дискретное строение вещества",
  "subtitle": "Подзаголовок под шапкой",
  "sections": [                    // разделы суфлёра
    {
      "title": "1. Молекулы и дискретность вещества",
      "text": "Текст урока, ключевые слова в фигурных скобках: {молекула}.",
      "chain": ["Опорный пункт 1", "Опорный пункт 2"]   // опорная цепочка (необязательно)
    }
  ],
  "flashcards": [                  // флеш-карточки (необязательно)
    { "cat": "Определение", "q": "Вопрос?", "a": "Ответ." }
  ],
  "timeline": [                    // хронограф (необязательно, напр. история)
    { "date": "1492", "title": "Колумб", "text": "Открыл Америку." }
  ],
  "quiz": [                        // экспресс-тест (необязательно)
    { "q": "Вопрос?", "opts": ["А", "Б", "В", "Г"], "correct": 1 }
  ]
}
```

### Инструменты-помощники (`tools`)

В тренажёре под шапкой появляется ряд кнопок «🧰 Помощники», если у предмета в `subjects.json` есть массив `tools` (код — `tools.js`):

```jsonc
"tools": [
  { "id": "periodic", "icon": "🧪", "title": "Таблица Менделеева", "type": "periodic", "data": "tools/periodic.json" },
  { "id": "mrcalc",   "icon": "🧮", "title": "Калькулятор Mr",     "type": "mr-calc",  "data": "tools/periodic.json" },
  { "id": "si",       "icon": "📏", "title": "Единицы и приставки СИ", "type": "tables", "data": "tools/si.json" }
]
```

Типы: `periodic` (таблица Менделеева в оформлении учебника: 18 групп с подписями IA…VIIIA / IIIB…IIB, цвета блоков, красная линия, массы из поля `m` в `periodic.json`; по клику — период, группа, валентность из § 9 и формулы учебника, где элемент встречается; кнопка «📖 Элементы § N» подсвечивает элементы открытого параграфа), `mr-calc` (калькулятор относительной молекулярной массы по формуле со скобками), `valence-calc` (калькулятор валентности: определение валентности по формуле бинарного соединения и составление формулы по валентностям, данные — `tools/periodic.json`), `tables` (набор таблиц: `{"tables":[{"title","columns","rows"}]}`), `image` (поле `src` — картинка, например таблица растворимости), `html` (поле `html`). Файлы данных лежат в `data/<id>/tools/`.

#### Режимы окна помощника

В шапке помощника четыре кнопки: **⛶** окно по центру (по умолчанию), **◧** закрепить справа, **⬓** закрепить снизу, **🪟** плавающее окно. В закреплённых режимах урок остаётся доступным: страница сдвигается, ширину/высоту панели можно менять, потянув за край. Плавающее окно перетаскивается за шапку, размер меняется за правый нижний угол. Выбранный режим и размеры запоминаются в браузере. На узком экране «справа» автоматически становится «снизу». Esc закрывает только окно по центру.

#### Контекст открытого параграфа (`toolContext`)

Помощник получает контекст параграфа, который сейчас открыт (`getToolContext()` в `tools.js`). Калькуляторы Mr и валентности показывают блок «📖 Из § N» с формулами параграфа:

- **автоматически** — формулы находятся во всех текстах параграфа (суфлёр, карточки, хронограф, вопрос и правильный ответ теста; неверные варианты теста не учитываются). Калькулятор валентности берёт только бинарные формулы, где валентность определяется по элементу с постоянной валентностью и совпадает со значениями из учебника, и строит по ним пары для режима «Формула по валентности»;
- **вручную** — поле `toolContext` в JSON параграфа, ключ — `id` или `type` инструмента:

```jsonc
"toolContext": {
  "valence": {
    "formulas": ["HCl", "CH4", "CaCl2"],              // показываются первыми
    "pairs": [["Fe", 3, "O", 2], ["C", 4, "Cl", 1]],  // пары «элемент, валентность»
    "auto": true                                       // false — не искать формулы в тексте
  }
}
```

### Свои названия кнопок (`labels`)

Названия вкладок и кнопок хронографа можно переопределять — для предмета (в `subjects.json`) или для отдельного параграфа (в его JSON). Приоритет: параграф → предмет → значения по умолчанию.

```jsonc
"labels": {
  "speaker": "🗣️ Суфлёр", "flashcards": "🃏 Карточки", "timeline": "🧪 Формулы и расчёты", "quiz": "🎯 Экспресс-тест",
  "timelineMode": "Проверка:",                 // подпись перед кнопками хронографа
  "tlShowAll": "👁️ Показать всё",
  "tlHideLeft": "📅 Скрыть формулы",            // скрывает левую колонку (поле date)
  "tlHideRight": "🔍 Скрыть расчёты",           // скрывает правую колонку (title + text)
  "tlHideBoth": "🧠 Скрыть всё"
}
```

Указывайте только те ключи, которые нужно изменить.

### Картинки из учебника

Картинки лежат в `data/<id>/img/` и подключаются необязательными полями (путь — относительно папки предмета):

```jsonc
"sections": [{
  "title": "...", "text": "...",
  "images": [ { "src": "img/p13_fig70.jpg", "caption": "Рис. 70. ...", "width": 460 } ]   // width — необязательно (px)
}],
"flashcards": [{
  "q": "...", "a": "...",
  "image": { "src": "img/p13_fig71.jpg", "caption": "Рис. 71", "side": "a" }   // side: "a" — на обороте (по умолчанию), "q" — на лицевой стороне
}]
```

Клик по картинке открывает её на весь экран (закрытие — клик или Esc). Картинки учебников защищены правами издателя — для личной подготовки; не публикуйте их в открытом доступе.

Любой из массивов `flashcards` / `timeline` / `quiz` можно опустить — соответствующая вкладка не будет показана.

## Как добавить новый предмет

1. Создайте папку `data/<id>/` и положите туда JSON параграфов.
2. Добавьте объект предмета в `data/subjects.json` (скопируйте существующий, поменяйте `id`, `title`, `color`, `sections`).
3. Если данные ещё не готовы — `"status": "planned"`, `sections: []`.

## Как добавить параграф в готовый предмет

1. Создайте `data/<id>/p<N>.json` по формату выше.
2. Добавьте тему в `sections[].topics` предмета в `data/subjects.json`: `{ "p": N, "num": "§ N", "title": "...", "desc": "..." }`.
3. Проверьте: `node scripts/check-data.mjs`.

Подробный порядок работы (сканы, OCR, вырезка рисунков, требования к содержанию) — в [`AGENTS.md`](AGENTS.md).

## Источники контента

Уроки готовятся из PDF-базы `D:\github\pdf-book-splitter\output\<папка_источника>\` (поле `sources` в реестре). PDF в платформу не встраиваются — из них подготавливаются JSON-данные тренажёров.
